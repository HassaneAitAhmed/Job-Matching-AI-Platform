# Screenshots Directory

This directory contains screenshots demonstrating the project's algorithms and results.

## Required Screenshots

### 1. time_comparison.png
**Purpose:** Show execution time comparison across all algorithms
**Content:** Bar chart or table comparing:
- A* with ML
- Greedy A*
- A* Assignment
- Genetic Algorithm
- CSP
- Global Search

**To generate this screenshot:**
Run all algorithms with the same dataset and capture timing results.

### 2. search_output.png
**Purpose:** Show example output from one of the search algorithms
**Content:** 
- Job offer details
- Top 5 matching candidates
- Compatibility scores
- Detailed breakdown of matching criteria

**To generate this screenshot:**
Run any algorithm (e.g., `python heuristic_withML.py`) and capture the output.

---

## How to Add Screenshots

1. Run the algorithms and capture outputs
2. Save screenshots as PNG files in this directory
3. Update the main README.md if filenames change
4. Ensure images are clear and readable

**Recommended Image Size:** 1200x800 pixels or similar
**Format:** PNG (preferred) or JPG
**Quality:** High resolution for clarity
