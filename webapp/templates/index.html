The Algorithms

A* Search

Best-first search over a hierarchical cluster tree with an admissible heuristic. Returns exactly the same top results as scoring everything, while scoring only a fraction of the items.

Optimal top-k

Greedy Best-First

Follows the heuristic only (f = h). Fewer expansions, but it can miss better matches in other branches.

Not optimal

CSP Solver

Hard constraints (sector, contract, education, distance, salary, experience) with node consistency and forward checking. It relaxes constraints automatically when nothing fits.

Strict filtering

Genetic Algorithm

Assigns a batch of seekers to job posts while respecting post capacities. It is benchmarked against the exact optimum (Hungarian algorithm).

About the Platform

How a match is scored

Each match is scored on seven criteria, each from 0 to 100%. The overall score is a weighted average. Weights depend on who is searching; for example, employers weight location and experience more heavily. Every result shows its own breakdown.

  • Technical skills: share of the job's required skills that are covered (TF-IDF soft matching)
  • Location: decays with road distance between cities
  • Experience: inside the required range, with penalties below or above it
  • Education: penalised for each level below the requirement
  • Salary: penalised when the offer is below the expectation
  • Sector and contract type: match or no match
